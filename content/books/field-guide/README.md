# Muscular America Field Guide — Content

Compact, browsable entries for gym and training practice.

## Section folders

| Folder | Intended domain |
| --- | --- |
| `front-matter/` | Title, how to use, disclaimers |
| `foundations/` | Intention, focus, consistency, starting points |
| `training/` | Exercise selection, strength, conditioning, mobility |
| `gym-environment/` | Etiquette, signals, equipment care, space respect |
| `nutrition/` | Practical fueling notes (non-prescriptive) |
| `recovery/` | Rest, soreness context, recovery habits |
| `tracking/` | Progress tracking and useful measures |
| `goals/` | Short-term, mid-term, and long-term markers |
| `back-matter/` | Glossary pointers, references, indexes |

## Entry stance

Short encounters. Observation before instruction. Practical rationale. Trivia and principles welcome.

Not a textbook. Not a dense training manual. Not a clone of other publishing properties.

Section folders may be reorganized later. Prefer stable entry `id` values over hard-coded paths.
See `docs/05_FIELD_GUIDE_ARCHITECTURE.md` and `docs/10_CONTENT_MODEL.md`.
